Open-Source-Projekt · GitOps-Homelab

Drei Cluster. Ein komplettes GitOps-Homelab.

capulus-core ist das GitOps-Herz eines Homelabs aus drei k3s-Clustern: Ansible provisioniert gehärtete Ubuntu-Hosts, ArgoCD rollt alles aus Git aus, neue Versionen wandern geprüft von ENTW über TECH nach PROD, und Tailscale sorgt für Zugriff ganz ohne offene Ports. Alles reproduzierbar, alles in Git.

Drei Bausteine

Infrastruktur, Deployment, Sicherheit – aus einer Hand.

Jeder Baustein ist für sich verständlich, entfaltet sein volles Potenzial aber im Zusammenspiel – vom ersten Ansible-Lauf bis zur laufenden App im Cluster.

Infrastruktur als Code

Gehärtete Ubuntu-Hosts, drei k3s-Cluster und alle Basisdienste entstehen automatisiert per Ansible – reproduzierbar und vollständig dokumentiert.

GitOps mit ArgoCD

Neue Anwendung? Ordner unter argocd/apps/<cluster>/ pushen – ArgoCD erkennt und deployed sie automatisch. Neue Versionen laufen erst auf ENTW, dann TECH, dann PROD.

Warum capulus-core

Gebaut, um wirklich zu laufen

Kein Demo-Projekt, das nur einmal im Blogpost funktioniert hat – capulus-core läuft bei mir seit Monaten produktiv und wächst mit jedem neuen Dienst weiter.

Automatische Updates

APT-Security-Patches, k3s, Helm-Charts und alle Apps aktualisieren sich selbstständig.

30+ Self-Hosted Apps

Von Nextcloud bis Vaultwarden – vorkonfigurierte Dienste für Fotos, Passwörter, Doku und mehr.

Modular per Helm/Kustomize

Jede App lebt in ihrem eigenen Namespace – einzeln hinzufügbar, aktualisierbar, entfernbar.

MIT-lizenziert & offen

Der komplette Code ist öffentlich auf GitHub – nachvollziehbar, forkbar, frei nutzbar.

Bereit, dir das genauer anzusehen?

GitOps-Code, Ansible-Playbooks, iOS-App und über 150 Doku-Seiten liegen offen auf GitHub – schau vorbei, stell Fragen oder forke das Projekt.
