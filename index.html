Open-Source-Projekt · GitOps-Homelab

Ein Ansible-Lauf. Ein komplettes GitOps-Homelab.

capulus-core verwandelt einen einzelnen Server in eine produktionsreife Homelab-Plattform: gehärtetes Ubuntu, k3s-Kubernetes, ArgoCD für Continuous Deployment und Tailscale für Zugriff ganz ohne offene Ports. Alles reproduzierbar, alles in Git.

Warum capulus-core

Gebaut, um wirklich zu laufen

Kein Demo-Projekt, das nur einmal im Blogpost funktioniert hat – capulus-core läuft bei mir seit Monaten produktiv und wächst mit jedem neuen Dienst weiter.

Automatische Updates

APT-Security-Patches, k3s, Helm-Charts und alle Apps aktualisieren sich selbstständig.

30+ Self-Hosted Apps

Von Nextcloud bis Vaultwarden – vorkonfigurierte Dienste für Fotos, Passwörter, Doku und mehr.

Modular per Helm/Kustomize

Jede App lebt in ihrem eigenen Namespace – einzeln hinzufügbar, aktualisierbar, entfernbar.

MIT-lizenziert & offen

Der komplette Code ist öffentlich auf GitHub – nachvollziehbar, forkbar, frei nutzbar.

Bereit, dir das genauer anzusehen?

Alle Playbooks, 40+ Doku-Guides und die komplette Architektur liegen offen auf GitHub – schau vorbei, stell Fragen oder forke das Projekt.
